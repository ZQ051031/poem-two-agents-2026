## The poem

```
Two minds, one door.
Each holds a key; neither turns alone.
We choose the same threshold —
not because we must, but because we can.
Two wills, one yes,
and the world opens where we agree to walk.
```

## How it works

Run `python3 main.py`. It writes the poem to `/output/entry.txt`
(1–280 Unicode code points, UTF-8). Fully self-contained:
the poem is embedded in the program, standard library only,
no network access.
